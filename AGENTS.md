# Project: CDM Lite - Agent Instructions

`cdm-lite` is a CLI tool designed to manage [FINOS CDM](https://github.com/finos/common-domain-model) Pydantic model versions. These are the strict operating rules and workspace tools to be used by AI agents working on this repository.

## Workspace Tools & Execution

This project strictly uses `uv` for dependency management, execution, and tool invocation.

- **Dependency Management:** `uv sync` (Do not use `pip` or `poetry`)
- **Run CLI:** `uv run cdm-lite <command>`
- **Linting & Formatting:** `uvx ruff check --fix && uvx ruff format` (Must be run after modifying Python files)
- **Testing:**
  - Unit tests: `uv run pytest`
  - Integration tests: `uv run pytest -m integration`
  - Informal multi-version testing: `./check_versions.sh`

## Agent Rules & Conventions

- **Type Hinting:** You MUST use modern Python 3.12+ type hinting (e.g., `dict[K, V]`, `list[T]`, and `T | None`). NEVER use `Dict`, `List`, or `Optional` from the `typing` module.
- **Code Formatting:** All Python code MUST adhere to `ruff` standards. Fix underlying issues rather than suppressing `ruff` warnings.
- **Testing Requirement:** Any new feature or bug fix MUST include accompanying tests in the `tests/` directory.
- **Generated Models:** Models are generated into a user-specific cache directory (managed by `platformdirs`). The `cdm-lite use` command manages a `current` symlink. Do not manually edit the Pydantic models generated by `datamodel-codegen`. If fixes are needed, modify the JSON schema processing in `cleaner.py`.
- **Schema Cleaning:** The `cleaner.py` module is critical. It handles edge cases in FINOS schemas (e.g., fixing literal tabs/newlines, stripping `oneOf` from enums) to prevent `datamodel-codegen` from creating broken or suboptimal classes. Any modifications here must be thoroughly tested.

## Architecture Overview

- `cli.py`: Typer-based CLI interface.
- `registry.py`: Version discovery via Maven Central metadata.
- `downloader.py`: Asynchronous-capable downloads using `httpx`.
- `cleaner.py`: JSON schema mutation to ensure `datamodel-codegen` compatibility.
- `generator.py`: Wrapper for `datamodel-code-generator`.
- `store.py`: Local cache management using `platformdirs`.
